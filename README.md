# Dota 2 Monitor Bot

Telegram‑бот для отслеживания новостей и патчей на официальном сайте Dota 2.

## Функционал
* Отслеживание новых новостей (https://www.dota2.com/news).
* Отслеживание обновлений патчей (https://www.dota2.com/patches).
* Отправка уведомлений в Telegram при обнаружении изменений.

## Установка

1. Клонируйте репозиторий.
2. Установите зависимости: `npm install`.
3. Создайте файл `.env` с вашими токенами.
4. Запустите бота: `npm start`.

## Настройка

1. Получите токен бота у @BotFather.
2. Получите ID чата через @userinfobot.
3. Заполните `.env` согласно примеру.
